Политика конфиденциальности

Приложение YT используется владельцем YouTube-канала для автоматической загрузки и планирования публикации собственных видео через YouTube Data API.

Приложение не собирает персональные данные сторонних пользователей. OAuth используется только для доступа к YouTube-каналу владельца. Данные третьим лицам не передаются и не продаются.

Токены доступа хранятся на сервере владельца канала и используются только для работы автозагрузки.
