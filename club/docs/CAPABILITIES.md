# Клуб-бот: каталог возможностей

Краткий справочник **всех функций** бота клуба на бизнес-языке.  
Для копирайта и сценариев участника см. также [`OVERVIEW_FOR_READERS.md`](OVERVIEW_FOR_READERS.md); карта автодожимов — [`FOLLOWUP_MAP.md`](FOLLOWUP_MAP.md).

---

## 1. Вход и знакомство

| Функция | Что делает |
|---------|------------|
| **Старт** (`/start`) | Регистрирует человека, показывает приветствие (видео-кружок + текст). Учитывает, есть ли уже подписка. |
| **Особые ссылки на бота** | Подарок, реферал, промо-кампания, «Польза», доска добрых дел и др. — бот сам понимает тип ссылки и запускает нужный сценарий. |
| **Согласие с документами** | Один раз показывает оферту / политику / согласие; без принятия дальше по сценарию не пускает. |
| **Меню** (`/menu`) | Единый экран кнопок: оплата, подписка, клуб, поддержка, партнёрка, польза, подарки, доска добрых дел. |
| **Справка** (`/help`) | Список команд по уровню доступа (участник / админ / супер-админ). |

---

## 2. Диалог с цифровым помощником

| Функция | Что делает |
|---------|------------|
| **Переписка в личке** | Отвечает на текст как «менеджер клуба»: формат, ценность, условия, мягко ведёт к подписке. Не выдаёт себя за врача или духовника. |
| **Голос и фото** | Голосовые расшифровывает; картинки при необходимости описывает, чтобы ответить по смыслу. |
| **Кнопка «вступить»** | Под отдельными ответами может предложить переход к оплате. |
| **Эскалация кураторам** | При сбое или «не справился» — сигнал команде; человеку короткая фраза, что вопрос передан. |
| **Зеркало диалога в админку** | Копия переписки уходит в служебный чат; куратор может ответить reply → человеку в личку. |

---

## 3. Оплата и подписка

| Функция | Что делает |
|---------|------------|
| **Тарифы и оплата** (`/payment`) | Выбор тарифа, валюты, оплата через подключённого агрегатора (ЮKassa / BZB). |
| **Проверка оплаты** | Бот сам опрашивает статус ссылки (часто в первые сутки, реже потом) и выдаёт доступ после успешной оплаты. |
| **Подарить подписку** | Даритель платит → получает ссылку; получатель активирует доступ по ссылке. |
| **Моя подписка** (`/subs`) | Срок действия, продление, вход в клуб. |
| **Промо-тарифы** | Скидки и спецпредложения по промо-ссылкам и акциям. |
| **Оферта (PDF)** | На шаге оплаты можно выдать юридический документ. |
| **Ручной подарок от админа** (`/gift`) | Выдать дни доступа по Telegram ID без оплаты через бота. |

---

## 4. Закрытая группа клуба

| Функция | Что делает |
|---------|------------|
| **Доступ в клуб** (`/club`) | Одноразовая ссылка-приглашение при активной подписке; уже в группе — материалы / пост. |
| **Приветствие в группе** | Сообщение новым участникам (если включено). |
| **Уборка служебных сообщений** | Скрывает «вступил / вышел». |
| **Авто-реакции** | Сердечки в выбранной ветке форума. |
| **Ночная проверка состава** | У кого нет актуальной подписки — удаление из чата (с учётом льготных дней). |
| **Карточки удаления** | В админку: кого и почему убрали. |

---

## 5. Поддержка и обратная связь

| Функция | Что делает |
|---------|------------|
| **Поддержка** (`/support`) | Участник пишет одним сообщением → тикет с номером в админку (текст + вложения). |
| **Отзыв** (`/feedback`) | Тот же канал, режим отзыва о боте / клубе. |
| **Ответ куратора** | Reply на пост с номером тикета → ответ в личку, тикет закрывается. |

---

## 6. Привлечение и партнёрка

| Функция | Что делает |
|---------|------------|
| **Партнёрская ссылка** (`/affiliate`) | Личная ссылка «пригласи в клуб» + простая статистика (переходы, оплаты, бонусные дни). |
| **Реферальный учёт** | Фиксирует, кто кого привёл по ссылке `ref_…`. |
| **Рекламные ключи** | Отдельные метки входа для кампаний (ref-ключи) и касаний при оплате/промо (touch-ключи). |
| **Промо-кампании** (`/new_promo`) | Мастер: deep link `promo_…` со скидкой / спецтарифом. |
| **Программа «Польза»** (`/benefit`) | Подарок (молитва / подкаст) → позже мягкое предложение вступить. |

---

## 7. Доска добрых дел и «ангелы»

| Функция | Что делает |
|---------|------------|
| **Доска добрых дел** | Участники оставляют просьбы о помощи; другие откликаются, берут в работу, отмечают выполнение, оценивают. |
| **Подарок продления другу** | Действующий участник может оплатить продление другому участнику. |
| **Ангельский взнос** | Один платёж → случайные продления подписок нуждающимся на доске (по правилам пула). |

---

## 8. Автоматика в личку (без команды пользователя)

| Функция | Что делает |
|---------|------------|
| **Дожим лидов** | Тем, кто зашёл / писал / начал оплату, но не купил — цепочки напоминаний с паузами. |
| **«Застряли в диалоге»** | Пинг с кнопкой «получить ответ», если ассистент давно не ответил. |
| **Напоминания о конце подписки** | За 7/5/3/1 день, в день окончания и после — сценарий продления / удержания. |
| **Бонусный день / финал** | Отдельные письма вокруг льготного продления и финального касания. |
| **Проактив участникам** | Плановые короткие сообщения member-агента действующим подписчикам (по расписанию). |
| **Отказ («стоп»)** | Прекращает дожим и навязчивые касания. |
| **Тяжёлая тема** | Без дожима про оплату — только поддержка. |
| **Рассылки outreach в личку** | Пилотные дайджест / цитаты в DM (если включено настройкой). |

Подробная карта таймингов и сегментов — в `FOLLOWUP_MAP.md`.

## 9. Контент в группе клуба

| Функция | Что делает |
|---------|------------|
| **Ежедневный дайджест** | Сводка обсуждений за сутки в отдельный топик (обычно утром). |
| **Цитаты из Писания** | Короткие посты в топик по расписанию в течение дня. |
| **Ассистент топика «общение»** | Периодически разбирает сообщения в ветке и может отвечать (пилот / зеркало / временные ответы — по настройкам). |
| **Расписание клуба** | Ведение и публикация расписания; правки из админ-топика; дайджест расписания вечером. |

Тестовые команды для админов: `/digest_test`, `/scripture_pulse_test`, `/outreach_dm_test`, `/schedule`.

## 10. Массовые рассылки

| Функция | Что делает |
|---------|------------|
| **Мастер рассылки** (`/new_mailing`) | Текст, медиа, кнопки, аудитория, скорость; только в личке админа. |
| **Персональная ref-ссылка** | В письмо можно подставить личную партнёрскую ссылку каждого получателя. |
| **Отправка партиями** | Паузы между пачками, чтобы не упереться в лимиты Telegram. |
| **file_id медиа** (`/code_id`) | Админ присылает файл → получает технический id для рассылок. |

## 11. Аналитика и отчёты (админы)

| Функция | Что делает |
|---------|------------|
| **Общий отчёт** (`/report`) | Сводка метрик в личку; режимы с/без ИИ-разбора, legacy / v2. |
| **Библия → Клуб** (`/biblia_club`) | Воронка перехода из библейского бота в клуб. |
| **Отток** (`/churn`, `/otval`) | Кто ушёл + текстовый разбор. |
| **График** (`/graf`) | Картинка метрики за период. |
| **Тест-драйв** (`/td`) | Конверсия пробного тарифа. |
| **Просрочка по тарифам** (`/excluded`) | Профиль оплат у отвалившихся. |
| **Воронка рассылок** (`/mailing_funnel`) | Эффект конкретной рассылки. |
| **Воронка кампаний** (`/ref_funnel`) | Эффект рекламных / ref-ключей. |
| **Каталог ключей** (`/ref_key`, `/touch_key`) | Список и карточки меток входа / касаний. |
| **Лиды дожима** (`/followup_leads`) | Сколько людей в цепочках без лицензии. |

## 12. Админ-консоль и доступы

| Функция | Что делает |
|---------|------------|
| **Панель** (`/admin`, `/adm`) | Разделы со ссылками на команды. |
| **Список админов** (`/admins`) | Только супер-админ. |
| **Добавить / удалить админа** (`/admin_add`, `/admin_del`) | Управление правами по Telegram ID. |
| **Очистить свою переписку** (`/clear_my_chat`) | Админ удаляет свою личку с ботом (с подтверждением). |
| **Служебный чат** | Оплаты, тикеты, диалоги, удаления, сбои — по топикам форума. |

---

## 13. Что видит команда в служебном чате (без команд)

| Сигнал | Зачем |
|--------|--------|
| Успешные оплаты | Тариф, сумма, кто, откуда пришёл, подарок или нет |
| Тикеты поддержки / отзывы | Текст и вложения, номер заявки |
| Диалоги с помощником | Контроль качества и ручной ответ |
| Выбор тем на старте | Интерес «деньги / отношения» и т.п. |
| Ночная чистка группы | Кого убрали |
| Карточки окончания доступа | Сценарии expiry / бонусного дня |
| Сбои доставки | Письмо ушло не до конца |
